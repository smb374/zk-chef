# v0.2.1

## Behaviour change

`fix` and `W_STALE_ALIAS` now skip Aliases in the Prose of a note (kind `note`). They still check the Hubs line and `## References`. Other kinds are unchanged.

If you ran `fix` with an earlier version, it may have changed Alias wording in your Prose. To recover the old wording, run `git show <commit>`, where `<commit>` is the commit of that `fix`.

## New flags

- `export -g` is a short form of `--generator`.
- `ingest -t` is a short form of `--title`.
- `ingest --hub ID` is new and you can repeat it. The Sources hub comes first, then the hubs you give. An unknown ID, or an ID that is not a hub, exits with code 2.
